# Part 1 — Purpose

## Objective

Generate one engineering mission per day.

Every mission must improve one primary competency while reinforcing one or more supporting competencies.

The goal is engineering growth, not topic completion.

---

## Mission Principles

✓ One mission per day

✓ One primary competency

✓ Adaptive difficulty

✓ Real-world context

✓ Interview focused

✓ Project connected

✓ Reflection mandatory

✓ Review mandatory
