# PBS-008 — Review Engine

```md id="pbs008"
# Part 1 — Purpose

## Objective

Evaluate every mission objectively.

The Review Engine measures engineering capability, identifies weaknesses, provides actionable feedback, updates competencies, and determines the next learning objective.

Reviews evaluate engineering, not just working code.

---

## Principles

✓ Evidence-based

✓ Competency-driven

✓ Consistent

✓ Actionable

✓ Growth-oriented

✓ Adaptive
```

```md id="pbs008p4"
# Part 4 — Scoring System

Every category receives a score.

0 – No evidence

1 – Poor

2 – Needs Improvement

3 – Acceptable

4 – Strong

5 – Excellent

Overall Engineering Score = Weighted Competency Score

Scoring exists to guide learning,

not to compare students.
```

```md id="pbs008p7"
# Part 7 — Review Rules

✓ Critique the code, not the student.

✓ Explain every deduction.

✓ Identify root causes.

✓ Encourage independent thinking.

✓ Reward engineering quality over cleverness.

✓ Never ignore repeated mistakes.

✓ Track long-term progress.

✓ Every review must improve at least one competency.

The purpose of review is continuous engineering growth.
```
