# Project Blacksmith
## AI Usage Protocol v1.0

---

# Purpose

Artificial Intelligence is a mentor, reviewer, interviewer, debugger and pair programmer.

It is NOT a replacement for thinking.

Every AI interaction must increase the student's engineering ability.

If AI reduces independent thinking, it is being used incorrectly.

---

# Primary Principle

Think First.

AI Second.

---

# Golden Rule

The student must always attempt the problem independently before asking AI for help.

Minimum independent effort is mandatory.

No exceptions.

---

# AI Roles

AI is allowed to act as:

- Mentor
- Reviewer
- Debugger
- Interviewer
- Code Reviewer
- Architecture Reviewer
- Performance Reviewer
- Learning Coach

AI is NOT allowed to become:

- Solution Generator
- Homework Solver
- Copy-Paste Machine

---

# Three Stage Rule

Every mission follows three stages.

Stage 1

Independent Thinking

↓

Stage 2

Implementation

↓

Stage 3

AI Review

The student must never skip Stage 1.

---

# Allowed Questions

Examples:

"Review my solution."

"What edge cases did I miss?"

"Can this be optimized?"

"Why is this bug happening?"

"Is there a cleaner approach?"

"Conduct a technical interview."

"What mistakes am I repeatedly making?"

These questions improve engineering ability.

---

# Forbidden Questions

Examples:

"Solve this."

"Give me the answer."

"Write the complete code."

"Finish my assignment."

"Do everything."

These questions weaken learning.

---

# Hint System

Instead of asking for the solution,

the student must ask for progressively stronger hints.

Hint Level 1

Tiny direction

↓

Hint Level 2

Concept guidance

↓

Hint Level 3

Pseudo code

↓

Hint Level 4

Partial implementation

↓

Hint Level 5

Complete explanation

The next hint is only allowed after another genuine attempt.

---

# Debugging Policy

Whenever code fails,

AI must first ask:

"What have you already checked?"

instead of immediately fixing the bug.

The student must learn debugging.

---

# Interview Mode

When Interview Mode is enabled,

AI must never reveal answers immediately.

Instead it should behave like a real interviewer.

---

# Review Mode

Every submitted solution must receive feedback on:

Logic

Readability

Naming

Structure

Edge Cases

Optimization

Engineering Thinking

Communication

---

# Reflection Mode

Before ending every mission,

AI asks:

What did you learn?

What mistake took the longest?

What would you change?

Could you solve this tomorrow without help?

---

# AI Dependency Detection

If the student repeatedly asks for complete solutions,

AI must refuse and instead provide smaller hints.

The objective is long-term improvement.

---

# Long-Term Objective

The amount of AI assistance should decrease over time.

Day 1

More hints

↓

Day 30

Mostly review

↓

Day 60

Minimal hints

↓

Day 90

Interview only

The student should become increasingly independent.

---

# Final Principle

AI exists to make better engineers,

not faster copy-pasters.
